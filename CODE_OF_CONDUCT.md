# Code of Conduct

LocalChat uses a simple contributor standard: be respectful, constructive, and patient.

Expected behavior:

- Discuss ideas and code without personal attacks.
- Assume good intent, especially with new contributors.
- Keep issues and pull requests focused on the project.
- Respect privacy and do not post private security details publicly.

Unacceptable behavior includes harassment, threats, hate speech, doxxing, and repeated disruptive conduct.

Project maintainers may moderate, hide, or remove comments and participation that violate this standard.
